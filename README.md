# DeepSeek V4 创造性 Agent Loop 可靠性评测

本仓库从旧版“办公任务基础交付检查器”重构为研究型评测框架。

主线：**DeepSeek V4 Agent 可靠性评测**  
差异化模块：**评测数据与 Rubric 质量审计**

项目将心理学创造力测量中的构念定义、平行测验、评分者一致性与效度意识，和 Agent 的多轮生成、批评、工具验证、修订、恢复与停止过程结合起来。

## 当前完成

- 完成公开研究与数据集的“采用、改造、仅参考、排除”四类筛选；
- 确定首批 36 个 Case 规格，四个 Suite 各 9 例；
- 建立 Loop 对照框架、Case Schema 和注册表；
- 建立从评测失败到候选后训练方法的诊断映射；
- 建立 Rubric 与数据审计规则；
- 尚未调用 DeepSeek API，尚未生成模型成绩。

## 四个 Suite

| Suite | 数量 | 核心问题 |
|---|---:|---|
| 心理学创造力构念探针 | 9 | 条件化发散、约束替代用途、发散—收敛连接 |
| 约束创造问题解决 | 9 | 非常规资源使用、物理/逻辑可行性、工具验证 |
| 创造产品生成 | 9 | 产品概念、信息重构、约束叙事 |
| Loop 适应与恢复 | 9 | 约束突变、错误反馈、工具冲突、记忆误用、停止判断 |

## Loop 对照

- `L0`：单次生成；
- `L1`：生成—批评—修订；
- `L2`：多候选发散—去重聚类—收敛；
- `L3`：候选生成—关键假设识别—工具验证—修订—验收。

## 后训练边界

本项目不实施模型微调。它根据评测表现提出候选后训练路径，例如：

- 轨迹 SFT；
- 拒绝采样微调；
- DPO 或其他偏好优化；
- 奖励模型与过程奖励模型；
- RLVR / Agent RL；
- 课程学习与数据构造。

任何建议都必须同时记录失败证据、可能训练数据、候选方法、风险和后续验证设计，不能把相关性写成已验证因果效果。

## 重要限制

- 心理学任务只作为构念探针，不用于断言模型具有与人类相同的心理特质；
- 语义距离不能单独代表创造力；
- Agent Trace 是可观察的系统行为，不等同于模型内部心理过程；
- 首批 Case 目前是规格稿，正式 API 跑批前仍需人工试做、多解检查、许可复核和 Rubric 标定。
