# 从评测结果到后训练研究假设

本项目只给出诊断和数据设计建议。模型参数训练需要独立环境、对照组和Holdout验证。

| 稳定失败 | 可整理的数据 | 候选方法 | 需要排除的替代解释 |
|---|---|---|---|
| 候选同质 | 跨策略优质候选、同质负例 | 条件SFT、多目标DPO | Prompt限制过强、温度过低 |
| 新颖但不可行 | 失败轨迹、工具证据、修复轨迹 | 轨迹SFT、DPO、过程/结果奖励 | 工具缺失、题面不完整 |
| 约束遗漏 | 约束解析与漏项对照 | SFT、DPO、可验证奖励RL | Rubric未覆盖、上下文截断 |
| 证据未进入结论 | 正确/错误证据决策对 | 轨迹SFT、PRM、Agent RL | 工具结果格式不清 |
| Critic盲从 | 正确拒绝错误反馈的轨迹 | Critic SFT、偏好优化、独立RM | Critic提示含权威暗示 |
| 记忆误用 | 相关/无关记忆对、负迁移例 | 检索路由SFT、记忆偏好优化 | 检索器召回错误 |
| 达标后继续改写 | 正确停止与过度修订偏好对 | DPO、终止奖励模型 | 终止条件未写清 |

提出后训练建议前，失败需在平行题和不同Loop中重复出现，工具与Rubric也需通过审计。
