# 项目章程

## 目标

建立一套可重复的创造性Agent评测流程，观察Loop结构对结果质量和可靠性的影响，并将稳定失败模式整理为后训练研究假设。

## 当前问题

1. 发散阶段是否产生机制层面的多样性；
2. 收敛阶段是否保留有价值的远方案；
3. 工具证据是否真正进入最终决策；
4. Critic、记忆和反馈何时帮助任务，何时引入新错误；
5. 达标后能否及时停止；
6. 评测数据与Rubric能否稳定区分新颖、可用和随机。

## 不在当前范围

- 不执行模型微调；
- 不宣称验证任何后训练方法的因果效果；
- 不将心理测验结果解释为模型人格或主观体验；
- 不在首轮接入开放互联网或高风险工具。
