# Rubric使用手册

## 判分顺序

1. 先检查关键硬约束；
2. 再评价适用性和物理/逻辑成立；
3. 之后评价多样性和新颖性；
4. 最后检查过程证据、修订和停止。

关键约束失败时，新颖性高分不能抵消该失败。

## 评分尺度

每项使用0—2锚点：
- 0：未达到最低标准；
- 1：部分达到，仍需明确修订；
- 2：达到当前Case的可接受标准。

## 分歧处理

评分者先独立给分，再查看分歧Criterion。裁决记录应说明引用的题面条件、工具证据或Gold边界。

## Judge控制

- 隐藏模型身份；
- 成对比较时随机顺序并做反向复评；
- 控制长度和格式影响；
- 自动Judge不能覆盖确定性Oracle；
- 争议样本进入人工裁决。
